# grove контекста — семья репозиториев под одним корнем

**Grove** — семья отдельных git-репозиториев под одной координирующей корневой директорией, у каждого свой CLAUDE.md, коммитящийся и публикующийся со своим репозиторием; в отличие от одного репозитория, который [Дерево контекста](context-tree.md) моделирует как одно дерево, у семьи нет общего дерева на диске — только общий корневой слой.

Харнесс агента грузит CLAUDE.md всех родительских директорий, пересекая границы git-репозиториев, — так корневой файл доходит до каждого leaf без единой написанной ссылки. Это работает, только пока семья лежит на диске ожидаемой структурой, поэтому корневой README каждой семьи несёт раздел Setup с этой раскладкой: написанная гарантия превращает случайное расположение в контракт, а сборка уже зависит от неё через относительные пути между сиблингами.

Отсюда: смысл, повторённый в нескольких leaf, поднимается в корень и удаляется из leaf целиком, без указателя, — харнесс и так доставит корень. И отсюда же два запрета: leaf не несёт написанной ссылки наверх, а корень не перечисляет, кто его читает. Таблицы маршрутизации по владению — другой жанр и остаются: они отвечают «куда положить задачу», а не «кто меня читает».

Проход выравнивания семьи начинается с проверки этой гарантии вживую и только затем поднимает смысл.
