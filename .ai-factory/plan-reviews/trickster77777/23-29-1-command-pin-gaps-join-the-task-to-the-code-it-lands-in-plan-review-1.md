### Critical Issues

**1. The spec's guard on a task spec repeating a paragraph is in no step — and the plan's own Grounding step makes the violation likelier.**
Spec § Guards `:41` states: "**A task spec may repeat a paragraph from a document instead of linking to it, and that is not a finding.** An agent does not reliably walk to the leaf; it guesses a file's content from its name. Such a copy goes stale, and that is proper to this tier: the roadmap is the perishable seam between the documentation and the code, pruned as it closes, unlike the two surfaces it sits between." Nothing in the plan carries it — not in the two-ends step, not in the class-paragraph step, not in Verification.

This is not a guard that can be safely left implicit, because it is counter-default twice over. First, the global CLAUDE.md § "Documentation style" states "A fact's second home is always a link, never a copy" and § "Grounding claims" states one-home-per-fact — both resident in every session, so the implementing agent holds the opposite rule by default. Second, the plan's own Grounding step directs the implementer to read § "Grounding claims" and says "both are quoted into the new body's reasoning", pulling exactly that discipline into the file being written. An implementer following the plan as written, describing a walk that "follows named references to the leaf", is being handed the premise for a rule the spec forbids and denied the exception. The concrete failure: the produced command tells its reader that a task spec restating a paragraph of the governing spec instead of linking to it is a meaning hole to route to `aif-docs`, or a duplication to collapse — and every pinning pass from then on reports a finding the spec says is not one, on a copy the spec says is proper to this tier. Nothing in the plan's Verification would catch it, since no check looks for the rule's presence or its inverse's absence.

Add a step (or a clause on "State the two ends of a hole and the direction change moves in", which is where the docs-facing end already lives) requiring the file to state that a task spec repeating a document's paragraph rather than linking to it is not a finding, with the spec's reason: this tier is the perishable seam, pruned as it closes.

Carry the third mapping in the same sentence shape as the other two.
