**1. The enumeration of sites names one that can never fire and misses one that can — `src/skills/roadmap-decompose/SKILL.md` (task 2 of the plan).** *Blocking.*

The plan pins the paragraph to "three sites: create mode, the add action, and hook (d)". Against the files:

- **Create mode proper cannot present a preamble.** `roadmap-engine/SKILL.md:152-154` enters Create mode only when `$TARGET_FILE` **does not exist**, and `roadmap-decompose/SKILL.md:35-38` forbids inventing a phase header ("never invent a phase header to hang a number on"). So a first-run create pass has no phase headers in the file and mints none — the flat fallback, which the plan's own exit already covers, always applies. Naming create mode as a site where the read runs, two sentences from the exit saying there is nothing there to read, puts a contradiction into a skill body.
- **The `Rewrite` action is missed, and it is the reachable one.** `roadmap-engine/SKILL.md:248-250` re-runs "the Create-mode draft→confirm cycle (gather input, explore, draft in memory, apply the per-entry gate hook, confirm) **over the existing `$TARGET_FILE`**" — an update-mode action, over a file that can carry phase headers, preambles, `Governing spec:` lines and `Phase note:` pointers, redrafting every entry in them. That is precisely a moment "the phase's first entry is drafted" and precisely where the pointers exist. An agent running Rewrite, reading an enumeration of three sites that names neither Rewrite nor update mode, has been told the read does not apply.

The contract line (`roadmap-outline`-tier authority for this task) says the read runs "once per phase before its first task is written, **in every mode**", so closing this needs no decision above the task: state the unit as mode-independent — *once per phase, at the moment that phase's first entry is drafted, in whatever mode the draft runs* — and let the enumeration read as the sites where a preamble can actually be present: the create-mode draft cycle **as re-run by the update menu's Rewrite** (`roadmap-engine:248`), the **Add** action (`:241-242`), and hook (d) "Decompose existing" (`:73`) for the target task's phase. Keep the flat-fallback exit as the plan already has it — it then covers the first-run create pass cleanly instead of contradicting the enumeration.
