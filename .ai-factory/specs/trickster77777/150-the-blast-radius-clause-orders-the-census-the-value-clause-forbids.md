# Phase 56 — the blast-radius repair clause orders the census its own file forbids

`docs/counts-go-stale.md` sorts every number in a durable artifact into one of three things — contract, census, or measurement — and rules exactly one of them a defect: a census, "how many call sites there are, how they spread across files, how many files a sweep will touch," true at the moment of writing and false the instant a sibling task lands. Its one-sentence test: a number stays where the sentence would still read true after someone adds a member without touching it; a census cannot pass this by construction, since adding a member is exactly what falsifies it.

`src/commands/command-pin-gaps.md`'s **Blast-radius holes** clause orders precisely that census into a task spec, a durable artifact that outlives the run that wrote it: "Repair: a `Grep`/`rg` sweep whose enumeration goes into the task spec, never a sentence saying something may need updating." A spec built on that instruction writes sentences of the shape "exactly two production callers", "thirteen files reference the type" — true when written, false the moment the first task touching that surface lands, and read as verified authority by a planner who never re-checks a tally the way it would question a hedge.

The same file already refuses this identical rot two clauses above, for a line number, and states the reason in the open: the **Value holes** clause pins a value "naming its source as the file and the name of the thing inside it that holds the value — a symbol, a heading, a bold lead-in — never a line number, because the spec outlives the numbering it was written against." That sentence is the whole argument the blast-radius clause needs — position rots, name does not — written a few lines above it, and it never reached the clause it applies to just as well.

`roadmap-engine`'s "**What a task spec holds**" paragraph feeds the same instruction to every skill that loads it for the task-spec shape: *what breaks on contact, enumerated rather than hedged*. `command-pin-gaps` names this paragraph as the root its own clause's shape derives from and does not restate. A repair confined to the command leaves this root ordering the same census back in for every other caller of the engine — `roadmap-decompose-skeleton`'s contract-task lens, `roadmap-outline-deep`'s phase note, and whichever future skill loads it next.

The repair the divergence names, stated as shape rather than skill text to paste: the **rule** that defines the affected set, the **literal sweep** that finds it on demand, and the **invariant** the sweep's result must satisfy after the change — replacing the enumeration itself, never the sweep that produces it. The clause's own tail is correct exactly as it stands and needs no repair: "A sweep too large to enumerate is itself a finding: report the search and its count with owner `roadmap-decompose`." That count lands in a chat report to the orchestrator, ephemeral and dated by its own nature, not in a spec that outlives it — the spec/report boundary is what any repair here must preserve, and the tail already respects it; only the ordinary-sized repair line does not.

Field evidence, read directly rather than taken on a report's word: `/Users/max/projects/tradeoxy/tradeoxy_broker/.ai-factory/specs/0011-substitutable-setup-managers.md` § "Blast radius — every call site whose compile-time type changes" already carries the repaired shape, not the one the command currently orders. Its rule: "every call resolving through `App.shared.strategySettingsManager` or `App.shared.subscriptionManager` has its receiver's compile-time type change from the concrete class to the new protocol existential." Its sweep, literal and re-runnable: `` grep -rn "App\.shared\.strategySettingsManager\|App\.shared\.subscriptionManager" Sources/ ``. Its invariant: "every match the sweep finds resolves to a member already declared on the corresponding protocol above... a match resolving to anything else means the protocol's member set is incomplete and this task is not done." No roll-call of files, no per-handler tally — the scope decision the same section also carries (which manager moves, which stays) is a contract and survives as prose, untouched; only a census would have needed removing, and none was there to remove.
