# The buffer section's heading and opening clause name what it now holds

## Current state (grounded, read fresh)

`src/skills/agent-architect/SKILL.md`'s buffer section opens with a heading and a clause that both describe the file as private, single-party, compact-survival state: the heading reads "## Your buffer is yours alone", and the section's opening sentence reads "Keep one buffer file for whatever of your own state must survive a compact: the editor's handle, any pairing role the user has assigned for the session, and the deferral entries below."

Directly beneath that opening sentence, the same section now describes the editor holding part of that same file: the settled zone is read by the editor as its own working context, and the section's own second paragraph states the announce-obligation — "When the memory the hand holds moves, you name the change to the editor in the same act as the write." The heading and the opening clause were both written before that paragraph existed, and neither has been revisited since; both still describe the buffer as though the editor never touches it, one section below the paragraph that says otherwise.

## The change

The heading and the opening clause come into line with what the section already describes below them. The heading stops claiming the buffer as the architect's alone; the opening clause stops framing the whole file as compact-survival state belonging only to the architect. What survives from each: the heading still names something true and load-bearing — the architect is the buffer's only *writer*, a fact the section's closing sentence already states ("It is the one file you edit directly: you are its only writer") — and the opening clause still lists what the architect keeps there and still ties the deferral entries and the recording items to survival across a compact, since that much is unchanged.

Nothing else in the section moves: not the announce-obligation, not the occasion-and-form paragraph, not the deferral-format paragraph, not the pointer to `architect-editor-engine`.

## Blast radius

The by-name reference to this heading elsewhere in the file — the rescoped inventory paragraph's "(see 'Your buffer is yours alone')" — is rewritten to quote the new heading's own wording, whatever the task settles on, so the reference moves with the name rather than being verified against it.

No other file names this heading: `editor.md`, `architect-editor-engine`, and `docs/paired-loop.md` refer to the buffer by what it is, never by this section's title. Renaming it touches no cross-file reference.
